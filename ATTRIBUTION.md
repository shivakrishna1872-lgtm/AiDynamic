## DynamicIsle

This project adapts the floating island window configuration and top-center screen/menu-bar positioning pattern from [DynamicIsle](https://github.com/sarthakpant772/DynamicIsle), specifically its `IslandWindow.swift` design. The project UI, mascot, and other agent behavior are separately implemented here.
